一个可直接投入使用的 AI 技能包（Skill）——把 `SKILL.md` 交给任何支持技能机制

## 怎么用

1. 把本仓库整个目录放进你的 skills 目录，例如 `~/.skills/guanfu-shishen-persona/`；
2. 在 AI 助手对话中按 SKILL.md 里描述的触发方式调用；
3. 零依赖、纯知识方法论包——不联网、不调付费接口。

```bash
git clone https://github.com/guanfujushi/guanfu-shishen-persona.git && cp -r guanfu-shishen-persona ~/.skills/   # 一键下载并装进 skills 目录
```
